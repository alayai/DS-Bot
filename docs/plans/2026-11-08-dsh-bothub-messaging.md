# BotHub：场景内消息与受理回执

2026-11-08，推进 P3 / BH-013。开始时进度：v0.1 58%，完整计划 41%。

## 本轮范围与契约

- Bot 详情支持纯文本快捷发送，最多 4000 字符。公共区／2D 总览发送到该 Bot
  当前私聊；群房间发送到群的主会话，按既有群规则分发，不直接操纵成员隐藏 Session。
  界面明确标注目标群及公开范围。不自动添加 @；用户可按群规则输入提及。
- 普通 Agent、子 Agent、本轮不支持的附件和审批继续使用原生会话。
- 新增 DS Bot 桥接能力 `messaging: 1`，保留监控协议 2 和旧版只读兼容性。
  BotHub 不直接调用旧 `api/bot/send`。需要升级配套 DS Bot 才能使用新发送入口。
- 采用公开 `sessionController.prompt({requestId, sessionId, mode:"queue", content}, signal)`，
  `accepted: true` 仅表示受理，绝不表示模型任务成功。

## 可靠性与权限

- 浏览器生成 UUID；服务端将 workspace、Bot、群、正文的摘要与实际目标 Session、
  时间及状态写入 DS Bot 自有目录的命令台账，再派发。台账不保存正文。
- 相同 ID、相同载荷返回原状态；不同载荷拒绝。凭证不自动淘汰，
  上限 2048 条；到限拒绝新请求，保留原生会话。不能通过淘汰凭证重新发送旧 ID。
- 派发前再次验证 writable、workspace、Bot 存在、群成员关系及固定目标；
  只读 UI 与服务端同时禁止发送。接口仍由宿主认证；拒绝跨站请求和越界输入。
- 网络超时或派发后异常为 unknown；不自动重发。查询原凭证和公开
  Session projection／有界 history page，可凭 `source.rpcId` 确认受理。
  找不到证据保持 unknown，并提供原会话入口，不能把未查到解释为未发送。
- 受理凭证落盘失败、重启、段切换不允许重新解析到新段后再次发送。
  不宣称端到端 exactly-once，也不覆盖磁盘毁损或手工删除台账。
- 草稿仅在当前插件内存；会话存储只保留命令 ID 与目标用于刷新后的回执查询，
  不保存正文。存储不可用时不妨碍使用，刷新后可在原会话核查。

## 公开 API 核对

锁定基线 `@deepseek-ai/dsh-api-session-controller` 0.2.1-rc.4 的 README 与
公开 types：prompt 接受稳定 requestId，返回 `{accepted:true}`；同请求 ID
已入队或入日志时不重复插入。projections 提供 sequenced/asOfSeq 和 inbox；
page 提供带界限的历史记录。`dsh-agent` 公开 inbox 的 next-turn／next-step
及 agent/inbox/spliced.inserted；`dsh-session` 公开 user/message.data。
仅使用公开服务，不修改或导入 DSH 私有实现。

## 已完成实现与验证

- DS Bot 新增 `monitor-commands.js`，提供持久化受理凭证、并发去重、
  派发前权限及目标复核、有界历史恢复；BotHub 新增消息状态存储和详情输入框，
  通道仅转发白名单字段。插件卸载会终止请求，迟到回执不会继续触发会话导航。
- DS Bot 完整单元测试：1599 通过、2 跳过、0 失败；BotHub：39 通过、0 失败。
  两客户端生成一致性检查与 lint 通过；DS Bot 原有 lint 警告仍存在。
- 真实隔离 DSH + mock 模型验证了私聊、群主会话发送、切换目标时草稿隔离、
  重复请求去重、同 ID 不同正文拒绝、受理后浏览器响应丢失时查询恢复、
  刷新后的凭证恢复、打开原群会话和 390px 布局。浏览器无 pageerror。
  真实接口拒绝跨团队、非 Bot 目标、超长输入、跨站及未认证请求。
- 将隔离台账的两条记录恢复为 pending 后重启宿主，公开回执接口从真实
  DSH 记录找回私聊、群聊受理证据；重复提交原请求后观察 5 秒，新增模型调用为 0。
  这验证的是该故障窗口下的恢复，不等于全场景 exactly-once。
- 宿主完整 smoke 复测 **52 步全部通过**。第一次运行有三次 `api/bot state`
  连接重置；停止另一个测试宿主和浏览器后，重置隔离 smoke 台完整重跑通过。
  尚未确定第一次连接重置的根因，不能据此声称已修复环境或宿主的连接问题。

自动化交互验证中的延迟与丢包由测试浏览器故意制造；正常演示不使用这些拦截。

## 交付边界

本轮修改 **DS Bot 和 BotHub 两个插件**；需要一起更新才能启用快捷消息，
旧桥接仍可监控和打开会话。本轮交付源代码与生成客户端，未重新打包、安装或发布。
既有 alpha 安装包不包含本轮改动，不能当作本轮验收产物。

普通 Agent／子 Agent 的快捷发送、精确停止、审批操作、SSE、运行历史、
长期稳定性与跨平台安装验证仍未完成。命令凭证最多 2048 条且不自动淘汰；
到限使用原生会话，后续需设计明确的归档方案。下一切片优先精确停止，
验证当前运行身份、权限变更与结束竞态，避免停止新启动的工作。
