# cua.18：虚机浏览器、长任务和周期任务

用户授权完成三项。维持当前 fork、公共 DSH API、现有审批/YOLO、独占租约、
generation/turn 隔离和未知输入不重放。Windows GUI 仍由用户测试。

## 同桌面 Firefox

新增 computer_browser_observe / computer_browser_act。观察返回桌面截图、当前
可见标签页和有界 DOM 摘要、元素引用。操作支持打开 HTTP(S) 地址、点击、填写、
返回及切换标签页。操作使用同一个可见 Firefox 和原有 profile；受限网络使用
既有 restricted profile。没有接口的已运行 Firefox 必须由用户关闭后重开，
不建立隐藏浏览器、不导入宿主 cookies、不提供任意 JS 或浏览器 chrome 执行。

通过 guest 内 Firefox 自带 Marionette 服务，仅连接 guest loopback。Broker
通过固定 docker exec 子进程传递限定命令；依照 Mozilla 顺序请求协议实现原创
客户端。控制端不发布端口。每次观察保存精确元素身份、URL/标签及有界结构，
操作前重新检查，变化则拒绝；不可见、敏感密码字段以及未支持的 frame 内容
通过现有截图和人工接管处理。释放/接管/停止关闭语义连接并使所有引用失效。

## 长任务

保存开始、最近进展和结束时间、当前步骤、等待原因、百分比及最近运行结果。
配置总时限和无进展时限；默认 60/10 分钟，30 秒检查一次。超时先持久暂停，
再撤销 CUA 权限并取消匹配的任务回合；旧回合不能继续。超时不是整个 Agent
的宿主工具沙箱，保留 assisted 说明。界面显示运行时间和排队等待原因。

## 周期任务

增加每日、每周（可选星期）及 IANA 时区，保留一次性任务。持久化同一任务的
下一次时间、运行次数和最近 20 次结果，不无限增长记录。夏令时不存在的时间
跳过，重复时间当天只执行一次。暂停/取消针对整个周期；失败、超时、运行中
重启或投递不明确均暂停后续周期并要求核验，不自动重试失败。

成功完成后才推进到未来的下一次时间，不并发、不积压重放。错过时间支持
“补执行一次”与“跳过”（超过计划时间 5 分钟仍未能投递视为错过）。DSH 或桌面
停止时不唤醒、不自动启动；重新可用时依策略处理。显式恢复中断任务仍先观察。

## 验收

单元测试覆盖时区/DST/错过、旧回合、超时及重复完成；真实 Firefox 验证同一
可见窗口、表单、导航、陈旧元素拒绝；浏览器界面验证周期表单及状态；全量
单测、生成文件、lint、隔离 mock DSH smoke 与独立解包。
