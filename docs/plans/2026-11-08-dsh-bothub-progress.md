# BotHub 开发进度台账

## 固定口径

用户要求：每轮完成后汇报本轮交付、当前完成百分比、变化和下一步。
百分比是按原开发计划功能与验收项估计的工程进度，不是工时实测或发布承诺。
阶段可以部分完成；演示、单元测试、安装、长期运行验证分别计算，不能互相替代。
阶段估计存在约 ±5 个百分点误差；保持权重不变，范围变化另记。

v0.1 包含 P0–P5；完整计划另外包含 P6/P7。完整计划权重固定为
v0.1 70%、P6 16%、P7 14%，参考原计划投入区间；P6/P7 当前尚未启动。

| 阶段 | v0.1 权重 | 本轮前 | 本轮后 | 主要尚未完成 |
|---|---:|---:|---:|---|
| P0 兼容性与契约 | 10% | 80% | 95% | 已验证固定 DSH/Cordis 基线；其他宿主版本与平台未承诺 |
| P1 桥接、模型、2D | 20% | 80% | 95% | 已补有界短任务终态、源事件顺序与 scope 测试；更广的 Agent 并发组合仍待试用 |
| P2 3D 场景与导航 | 25% | 90% | 100% | 首版范围完成；其他 GPU/浏览器适配在兼容性与稳定性跟踪 |
| P3 场景交互闭环 | 20% | 55% | 95% | 快捷消息及原生会话控制闭环通过；更多现场权限/审批组合待试用。直接精确停止受上游 API 限制，首版按原计划采用原生入口 |
| P4 稳定性与性能 | 15% | 50% | 90% | 已补事件风暴/100 Run、一小时三窗口、资源释放与安全回归；运行中热重载保留面板和其他平台未验收 |
| P5 发布与安装 | 10% | 40% | 95% | 候选打包、安装/禁用/升级/回滚、Web 与 Windows Electron 源码应用通过；小范围真实试用、签名安装器和正式发布未完成 |

计算：v0.1 = 各阶段权重 × 阶段完成度之和；完整计划 =
v0.1 × 70% + P6 × 16% + P7 × 14%。不对未实际完成的项目提前计分。

## 当前结论

MVP 首版功能已形成可安装的 `0.1.0-rc.4` 候选；按功能与验收的固定口径，
**v0.1 为 95.5%（约 96%），完整计划为 66.85%（约 67%）**。
相对上一轮正式基线 69% / 48.3%，分别增加 26.5 / 18.55 个百分点。
增长来自有界结束记录、可靠性压力测试、真实交互闭环、持续运行、成对安装和回滚证据；
没有把 P6/P7 或未完成的容器验收挪入分数。

本轮执行中口头报告的约 84% / 90% 为中间节点，最终以此表和验收报告为准。
rc.4 另外修复顺拐和接水往返不持杯，见
[动作修复记录](2026-11-08-dsh-bothub-character-motion.md#rc4-修复步态与持杯2026-11-08)。
仅 BotHub 变更，98 项测试和六个合成渲染检查通过；DS Bot 回归 1609 通过、2 跳过。
这是已有功能的缺陷修复，不额外增加百分比，也不将 rc.3 的一小时结果改记为 rc.4。

P3 原开发计划明确允许无法精确实现的停止入口交回原生；已实际验证群和私聊并发时
原生停止不会串上下文。直接 expected-run 原子停止没有实现，不再把它当作首版
所有交互的必需阻塞条件；上游能力就绪后继续单列。

工位私有桌面的 PNG、待机动画和放大查看属于追加需求。真实 Computer service +
测试 provider 证据保留；Docker engine 不可用，真实容器端到端仍未验收。
视频流与远程输入不是这一 MVP 的承诺。Windows Electron 源码应用已验证，
不等于已签名安装器或全平台验收。

下一步是候选试用和环境验收：恢复可用的容器引擎后验证真实桌面链路，补充运行中
插件热重载和其他平台覆盖，再决定正式发布。P6 历史分析、P7 空间编辑仍未启动。
完整证据、包校验和、命令和剩余限制见
[首版候选验收](2026-11-08-dsh-bothub-mvp-acceptance.md)。
