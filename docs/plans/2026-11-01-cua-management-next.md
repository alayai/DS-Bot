# CUA 后续五项管理能力

用户授权在当前 fork 分支完成旧存储核验、桌面资源、外部备份、任务队列和网络/磁盘策略。

1. 旧卷不直接改写引擎标签。扫描按当前登记记录确定候选来源，用户确认后保存绑定
   引擎、volume 创建时间/标签及不可变镜像的核验记录；归属不明或证据改变仍保护。
2. 每桌面 CPU/RAM 与网络策略持久保存，停止后确认配置。只重建可核验的停止容器，
   保留 home；写入操作意图，崩溃后恢复旧配置。启动核对引擎容量与并发准入。
3. 外部备份使用版本化、校验的流式格式。导出已停止的 home/checkpoint，导入只写
   新暂存卷，校验路径、数量、大小与哈希后发布，保留旧 home。浏览器原生文件
   选择/下载，独立于普通文件的 200 MiB 限制。不可通过客户端传入 Host 路径。
4. 任务队列走已有 DSH delivery/session API，记录目标、进度、状态和投递标识。
   暂停撤销 CUA 输入权限；恢复需重新观察。中断、投递不明、generation 变化均
   等待用户核验，不自动重放动作；任务结束需要明确结果，不把一轮结束当作成功。
5. 离线策略由引擎隔离；域名策略使用独立内部网络及仅允许指定域名的代理，拒绝
   IP/内网地址和绕过直连；无可验证后端时明确拒绝。磁盘准入/低水位保护与硬配额
   分开呈现。Docker Desktop 整盘配额依赖官方后端设置，不修改其私有配置或强停
   用户其他容器；现有 Podman/XFS 硬配额继续执行实际内核探针。

测试只用独立临时团队、容器和卷；Windows GUI 由用户测试。保持生成文件、打包
清单、文档和中英文 UI 一致。任务较大，按完成证据记录，不提前声称全量交付。

## 已实现的交付范围（cua.16）

- [x] 旧卷核验：本团队登记的 home/checkpoint/保留 home 可补充镜像证据；绑定
  引擎、创建信息、标签和选项。未知归属及改变后的证据继续受保护，不改写标签。
- [x] 每桌面 CPU/内存：停止后确认、保留 home、generation 隔离、配置中断恢复；
  启动检查引擎 CPU、总内存及其他运行桌面的预留。修改权限/YOLO 保留这些设置。
- [x] 外部备份：原生 Broker 导出当前停止的 home；逐文件校验及读回验证后导入
  新卷，保留旧 home。原生保存选择器不可用时按 64 MiB 编号分片下载；Windows
  文件窗口支持多选导入，自动排序并检查缺片。普通文件仍为单文件 200 MiB。
- [x] 任务队列：持久目标/进度、顺序投递、暂停/取消、显式完成/失败、确认恢复；
  旧回合及旧 generation 被拒绝，未知投递不重放。停止桌面或低磁盘保护也会中断
  正在执行的队列任务。真实 DSH AgentLoop 已验证观察和完成结果回写。
- [x] 网络与磁盘：离线模式；Docker 内部隔离网络+独立 HTTP/HTTPS 域名代理，
  拒绝内网目标、直连与外部 DNS；专用 Firefox 桌面快捷方式。磁盘启动/复制准入、
  每 30 秒低水位保护停止、持久原因及手动重启。保留现有已验证 Podman/XFS 硬配额。

明确边界：Podman 域名代理模式不开放；Docker 整盘硬配额不通过修改私有配置伪造。
低水位保护是采样保护，不保证快速写入绝不越线。备份不包含镜像，导入桌面需要
相同不可变镜像；文件没有加密/签名，包含浏览器登录状态。域名代理按目标域名限制，
不解密 TLS，也不隔离 Agent 的其他 Host 工具。Windows GUI 验收仍由用户执行。

## 验证及 Windows 建议验收顺序

自动化覆盖：旧证据/错误归属/陈旧确认、配置与引擎容量、拒绝客户端 Host 路径、
备份分片顺序与中断、恶意归档路径/哈希/镜像不匹配、任务状态/投递不明/暂停竞争/
旧回合/换代、磁盘保护。真实 Docker 验证资源限制、离线、允许域名访问、未允许域名/
内网IP/直连/DNS 拒绝，以及导入后内容和旧 home。真实 React 浏览器验证 65 MiB
备份分为两片下载、多选逆序上传导入、任务暂停/取消及重开页面。完整证据见
[VALIDATION.md](../../computer-runtime/VALIDATION.md) 的 cua.16 小节。

Windows 可按以下顺序验收：安装新插件并重启 DSH → 停止桌面设置 CPU/内存 →
测试离线及域名白名单 → 使用专用浏览器快捷方式 → 导出并确认本机备份文件 →
多选导入、核验文件并尝试回退 → 添加两个任务、暂停/恢复与重启恢复 → 查看低空间
保护状态。导入前先保留可用的外部备份；不要拿唯一的生产数据测试异常归档。

最终验证：1541 项单元测试通过、2 项跳过、0 失败；生成文件校验、lint 通过；
App 7/7、Python 20/20、mock DSH 52/52。交付 `0.2.5-cua.16`，已独立解包验证
30 个运行时文件及安装后的 Host 模块和生成客户端。
