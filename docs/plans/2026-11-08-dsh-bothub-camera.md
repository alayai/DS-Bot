# BotHub P2：三级镜头与键盘导航

延续总计划 §12.4、BH-011，以及“一群一房间”的已实现布局。本次只完善观察和导航；发送消息、审批与停止任务仍在原会话完成。

## 行为

- 总览点击席位：进入该席位所属房间并聚焦成员。同一 Bot 在不同群中的席位保持独立。
- 点击房间进入房间视角；成员视角显示当前成员标签，房间内其他角色仍保留。
- 面包屑显示“全部房间 → 群/公共区 → 成员”，支持直接返回房间或总览。
- Esc 从成员返回房间，再返回总览；空白点击仅取消成员选择。
- 场景可通过 Tab 聚焦。场景本身获得焦点时，方向键旋转、+/- 缩放、Home 重置当前层级视角。按钮保留默认键盘行为。
- 输入框、选择器、可编辑区域、输入法组合期间不处理快捷键；不影响页面其他区域。
- 状态轮询不重置用户旋转、缩放。只有导航层级或对象改变时恢复默认角度；成员席位位置变化时跟随新位置。
- 搜索/状态筛选取消成员选择。成员或群删除时退回有效层级。
- 2D 保持群上下文和详情；2D 总览的聚合选择切到 3D 时清除，避免错误映射到公共区席位。
- 镜头直接定位，无持续飞行动画；隐藏页面暂停绘制，卸载时释放渲染器、材质、几何体与监听器。

## 验收

纯函数测试覆盖镜头范围、导航对象身份、轮询稳定性、缩放边界和输入保护；构建、生成文件检查、单元测试、lint 通过。真实 DSH + 隔离 mock 台架验证三级往返、键盘、详情上下文、轮询、2D 切换、反复挂载、WebGL 降级及小屏。演示只产生本地文件，记录工作树与测试环境，不安装到用户 DSH。

## 实现与验收结果（2026-11-08）

- `camera.js`：独立的镜头目标/轨道状态，以及输入保护；`world.js` 使用该状态定位和处理键盘。
- `view.js`：选择席位进入对应群、位置导航、Esc 逐级返回、删除/筛选后的选择清理。
- 两份 README、英文/中文文案与生成的 `client.js` 同步更新。
- BotHub：24/24 测试通过；构建、生成文件检查和 lint 通过。
- DS Bot：1589 通过、2 跳过、0 失败；构建、生成文件检查和 lint 通过（保留仓库已有警告）。本轮无 host 行为改动，未重复上一切片的 host smoke。
- 真实浏览器：总览直接选群席位、群/成员三级返回、不同群详情隔离、方向键/缩放/Home、Tab/Enter、输入框与选择器 Esc 保护、从详情返回后的焦点恢复均通过。
- 两个轮询周期后，旋转/缩放后的标签投影位置保持不变。拖动不误选；空白点击取消成员但保留房间。
- 2D/3D 保持群成员选择；聚合 2D 选择切回 3D 不误选公共区。禁用 WebGL 自动降级，390px 下无横向溢出。
- 资源诊断用独立浏览器 context 包装原生 WebGL/ResizeObserver 计数：8 次完整卸载/挂载循环中，2D 时存活场景 context/observer 均为 0，3D 时均为 1。结束时累计创建 11 个、显式释放 10 个，最后 1 个属于仍显示的场景；随后关闭浏览器。此验证不等同于完整 GPU 内存泄漏证明。
- 被动验证及演示前后，隔离 mock 请求日志均为 12 条：新增模型请求 0。页面脚本错误 0。
- 首次冷启动浏览器导航超过 30 秒，随后延长测试导航等待至 120 秒完成验证；生产请求逻辑未改动。失败截图仅作诊断，未放入演示。
