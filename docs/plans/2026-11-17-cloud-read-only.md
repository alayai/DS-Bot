# 云端模式下本地 Bot 配置只读摘要

日期：2026-11-17。范围：dsh-server 融合阶段二；不发布云端 Bot，不改变本地会话运行位置。

DS Bot 提供 `ctx.botReadOnly` v1，`list(offset, limit)` 仅返回已加载内存中的 Bot ID、名称、角色、指令文本预览、模型引用和隐私标志。每页最多 10 个，指令最多 4096 字符。未初始化返回 `ready: false`，不会因查看摘要执行 load、refresh、save、模型请求、Agent 激活或目录操作。外部修改尚未被原运行时接收时，摘要明确仍代表已加载状态。

DSH 的 `dshCloud/readLocal` 是正式消费者：仅 Host owner 可调用，校验当前 cloud epoch，暂停模式仍可读；原 `/api/bot` 不放行。摘要不携带目录、工具参数、密钥、连接器、记忆或历史，不自动发送到服务器。用户输入的指令本身可能包含敏感信息，查看是本地显示，不承诺自动识别或清除文本中的秘密。隐私 Bot 的设置仅向当前 Host owner 展示，后续复制到云端需独立处理其禁止复制的规则。

提供服务的 effect 随插件卸载释放。用户已有的 Session 日志保持追加式原义，本功能不改写或迁移它们。测试覆盖初始化缺失、字段排除、分离返回值、分页和长度限制；DSH 侧另外验收身份、epoch 和执行限制。
