# BotHub：办公环境与公共设施

按用户要求，将群房间从角色展示平台推进为有实际陈设的办公室，公共区提供茶水、休息、斯诺克及健身设施。保持一个群一个房间、群上下文隔离和三级导航。

## 本轮实现范围

- 群办公室：木质办公桌、显示器、键盘鼠标、台灯、杯子、抽屉柜、带脚轮办公椅、书架与书籍、白板、时钟、绿植。
- 公共区：咖啡机、微波炉与茶水柜台；带球袋、球和球杆的斯诺克桌；沙发茶几；跑步机、哑铃架与瑜伽垫。私聊/Agent 工位保留在独立前区。
- 空间按家具实际占地扩展，预留过道；后墙保留办公室轮廓，侧墙采用剖切高度，避免挡住成员。
- 角色坐在工位前；选中范围、状态标记及标签保持明确。点击桌椅仍选择所属成员；点击公共家具进入公共区，不伪装成执行命令或游戏。
- 增加物体粗糙度、木纹/织物程序纹理和柔和阴影。物理材质使用独立的集中色板，界面控件继续沿用现有主题变量。
- 家具几何由本仓库原创生成，不下载第三方模型、图片或纹理。采用共享几何/材质与跨房间实例批处理，避免逐本书、逐个球增加 draw call。
- 环境只在布局变化时重建；普通状态轮询不创建家具资源。卸载释放实例缓冲、纹理、材质、几何体及阴影资源。
- 公共设施本轮为可浏览的场景陈设，不模拟 Bot 娱乐/健身，也不凭空改变运行状态。

## 验收

检查家具和工位的边界/相交、布局顺序稳定性、实例批次数上界及资源释放。保留现有镜头/群导航测试；真实隔离 DSH + mock 环境检查办公室、公共区、成员聚焦、2D/3D 往返和 WebGL 降级。提供当前源码运行的截图与本地连续演示，记录实际测试结果与性能限制。

行深排列房间。`furniture.js` 生成所有原创家具、程序纹理和跨房间实例批次。
`world.js` 增加半球光、柔和方向光阴影、坐姿角色和实例点击解析；阴影仅在场景
结构改变后重绘。成员标签与设施标识分开定位，近景保留工位上下文。

- BotHub：27/27 单元测试通过，build / check / lint 通过。
- DS Bot：1589 通过、2 跳过、0 失败；build、生成文件检查及 lint 通过，保留已有警告。本轮没有 host 改动，未重复 host smoke。
