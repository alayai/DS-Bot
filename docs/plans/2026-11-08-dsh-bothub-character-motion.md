# BotHub：角色工作与生活动作

按用户新要求，优先推进角色表现，精确停止仍保留在后续队列。本轮只修改
BotHub 客户端，不增加模型调用、宿主状态或执行权限。

## 行为与边界

- 工作中：快速交替敲键盘、身体轻微前倾、汗滴与周期性擦汗。
- 已观测空闲：站起来接水、喝水、伸展及哑铃；公共区可走到咖啡机或斯诺克桌。
  群内增加饮水机，群席位不跨房间，保持一个群一个空间的选择与消息上下文。
- 持续空闲：可趴桌短睡，闭眼、呼吸与漂浮 Zzz；不播放音频。
  这是装饰动作，不意味着 Bot 暂停、真实休息或不能接收任务。
- 等待审批／输入、等待协作、未知、连接失效时不得继续假装工作或娱乐。
  新任务立即改变状态标记，离席角色沿原路返回再进入工作姿态。
- 增加安静／正常／活泼三档，默认正常；仅活泼档持续表现日常活动。
  正常档状态变化后最多演示 5 秒。系统减少动态效果优先于档位；
  隐藏标签页暂停时间与绘制，不补播后台动作。
- 固定过道路径、同设施单人占用，角色骨架与道具复用资源。标签、点击、
  镜头跟随实际角色位置，但不会更换业务目标。没有完整人群避碰或桌球游戏规则。
- 动画在渲染器内推进；节能／均衡／精细分别限制 12／24／30 fps。
  不逐帧重绘静态家具阴影；动态角色不留下缓存阴影残影。

## 验收计划

验证状态与上下文隔离、动作中断返回、设施占用释放、过道边界、配置与减少动态
效果、隐藏／卸载清理。真实隔离 DSH + mock 检查工作到空闲、移动标签与选中目标，
独立合成场景验证全部动作及 20／50 席位动画开销；测试、构建、lint、一致性检查
与本地录制完成后补充结果。进度沿用固定权重，不把新增装饰算作执行控制完成。

## 实现与测试结果

- `activities.js` 管理每个群席位独立的动作、过道路线、设施占用及返回状态；
  `character.js` 提供共享几何的四肢骨架、杯子／水流／蒸汽、哑铃、汗滴、
  球杆／练习球和立体 Zzz。群办公室新增程序化饮水机。
- `world-renderer.js` 在动作期间按画质限制绘制频率，等待下一活动时采用一次性
  唤醒，避免静止角色持续绘图。不逐帧更新 React；禁用或卸载清理计时器、
  减少动态效果监听及设施占用。
- BotHub 45 项测试通过，构建、生成一致性及 lint 通过。测试覆盖 1／3／20／50
  席位过道边界与主要家具避让、共享设施排他、全部生活动作、睡眠等待、
  新工作中断返回、反复同状态轮询、静态档位、偏好异常与骨架资源复用。
- DS Bot 回归：1599 通过、2 跳过、0 失败；生成一致性与 lint 通过，保留原有
  lint 警告。本轮未修改 DS Bot 或 host 接口，不重复 host smoke。

## 单机场景基准

沿用 Windows Chrome／Radeon 890M 的隔离合成场景，1920×1080 场景、DPR 1，
所有角色处于工作状态。每档预热 0.8 秒，采样 2.5 秒；这是 CPU 绘制提交与
标签布局回调，不是 GPU 完成时间或真实模型吞吐。限制值是帧率上限，
本环境的定时器和 rAF 调度会使实际帧率更低。

| 席位 | 画质 | CPU 回调 p95 | 2.5 秒绘制帧数 | 最大绘制调用 |
|---|---|---:|---:|---:|
| 20 | 节能 | 2.4ms | 27 | 424 |
| 20 | 均衡 | 3.1ms | 46 | 424 |
| 20 | 精细 | 3.4ms | 47 | 424 |
| 50 | 节能 | 5.5ms | 26 | 994 |
| 50 | 均衡 | 6.0ms | 45 | 994 |
| 50 | 精细 | 6.5ms | 47 | 994 |

安静、断线、系统减少动态效果、正常档 5 秒结束后、活泼档等待下一活动时，
观察窗口内新增连续绘制均为 0。合成 visibilitychange 事件验证隐藏暂停与恢复。
10 次挂载／卸载后 WebGL context、buffer 和 texture 计数均归零。以上是有界
单机检查，不替代全天运行、100 Run、移动设备或完整人群避碰验收。
复现入口为开发基准页的 `runMotionBenchmark({count:20})` / `count:50`；
脚本与原始结果在 `.playwright-mcp/bothub-motion/benchmark.*`。
