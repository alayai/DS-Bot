# BotHub 投影事件同步与断线恢复

日期：2026-11-08。范围：P1 / BH-006 的 MVP。

## 公开接口与范围

固定 DSH 0.2.1-rc.4 的 `dsh-client-connection` 公开 exact Fetch route 接收
WHATWG Request / Response；物理载体负责认证与信任校验，只有 owner Peer 可以
访问 exact route。公开 `agent/status`、`agent/created`、`agent/disposed`、
`session/event` 可用作失效通知。不读取私有宿主实现，不修改 DSH。

BotHub Host 订阅这些通知，合并后重新读取已有 `botMonitor.snapshot()`；
没有原始会话、提示词、工具参数或输出进入事件流。多个页面共享一次采集。
周期核对补齐群成员、只读能力和旧桥接没有通知的变化。
本轮只修改 BotHub；保持现有监控与消息桥接协议兼容。

## 协议与一致性

- 新增 `GET api/bothub/events`。使用同源 cookie，不在 URL 中带令牌。
- 每个投影有 schema version、scopeKey、epoch、seq。
  workspace、桥接实例或只读权限变化会建立新的 epoch，丢弃旧缓存。
- 首帧是完整快照；后续 patch 对 entities/sessions/runs/groups 按 ID upsert/remove，
  同时更新能力和观测时间。序列是投影提交序列，不冒充 DSH 原始事件序列。
- `Last-Event-ID` 仅指示恢复位置，不选择工作区。缓存内连续补发；无法连续恢复
  则发完整快照。补发结束有 ready 帧，重新核对当前水位后才启用操作。
- 每个连接发送最新基线与订阅之间没有异步间隙；采集串行，
  旧桥接、旧生命周期或已关闭连接的异步结果不能回写。
- 缓存按条数和 UTF-8 字节数限制；慢消费断开，不无限排队。
  无订阅时停止周期采集与事件触发采集；卸载关闭流并清理计时器与监听器。

## 客户端

一个 store 共用一条 fetch SSE 流。保存最后连续应用的水位，重复帧忽略，
缺口/错误 epoch 强制拉新基线，网络中断保留最后已知状态并禁用操作。
带抖动退避重连；流不支持或反复失败则轮询，界面明确显示降级，并周期探测恢复。
认证失败清空数据并停止盲目重试，用户可重新登录后刷新。
DSH 公开 `connection/reset` 通知新的已认证连接建立时，也主动重新核对基线与能力。
隐藏页面主动关闭流，恢复可见时重新连接；停止、刷新和重挂载均隔离请求代次。
团队切换清空选择及房间筛选，草稿继续按 workspace 隔离。

## 边界与验收

这是当前状态投影的增量同步，不是持久历史日志。合并窗口或异步采集中发生并结束
的短运行可能不可见，不能保证保存每个终态或达到原计划 p95 ≤1 秒。
精确取消和跨平台发布仍不在本轮范围。

验收覆盖基线/增量/删除、重复/缺口、缓存淘汰、epoch 与 workspace 切换、
慢读者、通知风暴、无订阅/卸载、断线/超时/认证、降级与恢复。
执行两插件测试、构建一致性与 lint，以及隔离 mock 宿主 smoke 和真实浏览器验证。

## 已落地参数与权限边界

- 每个 Host 共享一份投影和缓存，最多 128 条增量 / 1 MiB，先达到者淘汰；
  每个连接按字节计背压，上限 1 MiB，最多 16 个连接。大于队列上限的
  基线会断开并触发客户端降级，不无限扩张内存。
- 通知 150 ms 合并，5 秒定期核对，采集超时 9 秒；采集期间收到通知，
  完成后继续安排下一次采集，不让最后一个变化落入空隙。
- 15 秒 ready 心跳；客户端首帧超时 10 秒、后续静默超时 35 秒；
  失败抖动退避上限 30 秒。流 404/405 立即降级，连续失败 3 次后降级。
  降级轮询成功间隔 2.5 秒，12 次成功后尝试恢复流。
- 浏览器 offline 立即停流并禁用操作，online 立即重连；页面隐藏主动停流。
- 连接最长 60 秒后重建，以重新经过 DSH 认证。已经打开的流对凭证到期
  的发现有最多约一个连接租期的延迟，不宣称逐帧重新认证。
- owner-only 的 exact route 是本轮授权边界；客户端不能指定 workspace、
  principal 或 scope。桥接版本、workspace、只读状态和服务实例在采集时重查。
- 补发的是已经提交的投影变更；没有足够连续缓存时直接发新快照。
  投影是原桥接的 best-effort 采集，不新增跨 Session 的事务快照保证。
- `src/shared/` 加入插件包清单，避免安装后 Host 缺少同步协议模块。
