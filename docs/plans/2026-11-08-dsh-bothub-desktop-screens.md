# BotHub：工位显示器接入私有桌面

用户已授权实施第一批 MVP：运行中的 Bot 私有桌面显示在该 Bot 的工位屏幕上，未运行时使用原创待机画面。这里的“打开”指桌面运行，不依赖独立查看面板是否打开。

## 范围与契约

- 复用认证的 `api/bot` 中 `computer-state` / `computer-preview`，不启动桌面、不接管、不发送输入，不调用模型观察工具。
- DS Bot 状态增加 `passivePreview: true`；预览参数 `passive: true` 不刷新桌面空闲计时。旧版缺少能力时只显示兼容性提示和待机画面，不用普通预览代替。
- 仅真实 Bot 绑定桌面；普通 Agent / 子 Agent 不借用父 Bot 的画面。同一 Bot 在多个群房间出现时共享画面。
- 按 Bot id、桌面 id、generation 校验身份；工作区改变、断线、页面隐藏、移出可见范围、卸载时清除旧图并取消请求。
- 第一批使用低频 PNG 预览，最多四个可见 Bot、两路截图并发，每轮至少一秒；状态五秒刷新。优先选中 Bot 和较大的屏幕。状态读取与预览超时，错误退避，不无限并发。
- 正常画面按比例缩放到有界 Canvas，再作为独立屏幕贴图；图片不写入监控 SSE、历史或浏览器持久化存储。
- 短暂 busy 可保留上一帧最多五秒并标记等待；停止、禁用、重绑定或不可恢复错误立即清除。不能把旧画面冒充实时桌面。
- 待机代码滚动为原创程序图形；仅活泼模式连续播放，正常模式短暂播放，安静及系统减弱动态效果使用静态画面。
- 第二批的放大查看和更流畅的实时流另行推进。本批不把 3D 点击转换为桌面鼠标/键盘输入。

## 验收

测试运行/停止、缺少能力、忙碌与过期、绑定代际、乱序完成、重复席位、隐藏/卸载、限流与资源释放；确认被动预览不延长自动休眠、不消耗模型观察绑定。执行两个插件的测试、生成检查、lint，以及 DS Bot host smoke。

浏览器验证使用隔离服务和测试数据；真实桌面运行环境不可用时必须分别说明集成测试/测试画面与真实桌面验证的边界。

## 第二批设计：放大查看

- 点击真实 Bot 工位的显示面打开只读窗口；详情页提供同等的键盘/2D 入口。普通 Agent 不借用 Bot 桌面。
- 使用原生模态 dialog，显示 Bot 名称、预览状态和只读提示；支持适应窗口、原始大小滚动查看。Escape 只关闭最上层窗口，关闭后焦点返回入口，保留场景视角。
- 沿用第一批被动 PNG 通道，打开窗口时暂停场景的截图，只采集当前 Bot。此批不实现视频流、启动桌面或输入控制。
- 窗口绑定工作区与 Bot 身份。工作区改变、Bot 删除或卸载时关闭并清图；断线、只读、页面隐藏、关闭开始时立即停止请求并清图。图片解码完成后再次检查取消和清图代际，防止迟到帧覆盖新桌面。
- 关闭使用 160ms 淡出，先清除图片再卸载。无尺寸/位移动画，适用于系统减少动态效果。
- 追加需求分三项跟踪：工位预览、放大查看、更流畅画面与真实容器验收；不改变原计划权重。

## 实现与验证（2026-11-08）

- `desktop-preview.js` 提供每场景共享的调度器：Bot 去重、最多四个来源、两路并发、能力检测、代际检查、失败退避、五秒画面过期，以及取消/卸载后拒绝迟到结果。
- `desktop-screens.js` 保留家具实例批处理，仅显示面增加独立平面；同一 Bot 跨房间复用贴图，待机/状态画面按状态共享。PNG 在浏览器缩小到 512 × 276 并保持原比例。实际传输仍是完整 PNG，没有宣称服务端缩略图或视频流带宽。
- `world-renderer.js` 按屏幕投影位置/尺寸和正面方向筛选来源，选中 Bot 优先；不见于视口、容器零尺寸、隐藏、断线、退出 3D 时暂停。工作区改变重新挂载场景。
- DS Bot `computer-state` 暴露被动预览能力。`computer-preview` 的 `passive: true` 不刷新 idle 时间，不允许携带控制票据；宿主请求取消信号传入截图操作。普通桌面面板的预览语义保持兼容。
- BotHub **74/74** 测试通过；DS Bot **1602 通过、2 跳过、0 失败**。两插件生成检查及 lint 通过，DS Bot 保留已有 lint 警告。
- 新后端测试验证：被动截图后模型仍能使用原观察绑定；反复被动截图不推迟自动休眠；停止后不会被截图启动；拒绝错误 generation/控制票据；取消截图释放操作占用。
- 完整隔离宿主 smoke **51/52**。既有 `Writer waits for the work it handed on, then answers with it` 未捕获 3 秒任务的等待状态。单独复验：3 秒任务仍未观测到等待，但交回证据存在；10 秒任务同时观测到正确的等待对象/来源及交回证据（`handoff-recheck.json`）。最大单次状态读取 158ms。这个结果支持短暂等待窗口与任务完成时序有关，不能记为完整 smoke 全绿；本轮未修改该用例或交接生产逻辑。
- 隔离真实 DSH + mock 团队浏览器验收：待机屏幕、2D/3D 往返停止请求、390px 布局、未认证请求 401；未配置桌面时只查询状态，没有启动/接管请求。页面错误 0。
- 另用真实 Computer service + 仓库 fake provider + 原创测试 PNG，在实际 WebGL 渲染器中验证实时贴图、竖屏比例、busy 保留/超时清除、停止、旧版能力回退、损坏图片恢复、断线、模拟可见性变化、跨群重复席位共享。八次场景卸载后的跟踪纹理及 WebGL context 均为 0；安静待机连续 2.4 秒没有额外渲染；页面错误 0。
