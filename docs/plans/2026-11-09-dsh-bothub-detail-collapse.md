# BotHub：成员详情按内容展开并可手动收起

用户要求截图中的空成员详情不占宽度，缩至最右侧，并增加收起按钮。
这是 BotHub 内部的成员详情，不是 DSH 整个右侧栏。

## 行为与实现

- 未选择或所选成员已失效时，不渲染大块空提示，只保留最右侧 36px 控制条。
  没有内容时展开按钮禁用，提示先选择成员。
- 点击 2D 成员、3D 标签或详情关系中的成员自动展开；详情具有内容时即使没有执行也显示。
- 提供带英文/中文名称、title 和 aria-expanded 的原创建图标按钮，支持键盘操作。
  手动收起保留选中成员、消息草稿、回执与进行中的发送；轮询不自动重新展开。
  再次选择成员或点击展开按钮恢复；过滤、清空选择或工作区切换后自动回到空收起态。
- 宽容器保留现有侧排，窄容器展开时仍上下排列；收起时控制条始终在最右侧，场景释放空间。
  不增加尺寸过渡或新动画，不修改 DSH、DS Bot Host、监控状态和用户数据。
- 仅在当前 feat/bothub-mvp 工作树继续本次 UI 修正，保留全部既有修改，不提交或发布。
