# BotHub 当前运行的原生控制入口

日期：2026-11-08。范围：P3 / BH-014 的公开能力核查与安全降级。

## 能力边界

当前台架固定使用 DSH `0.2.1-rc.4`。随包公开契约
`@deepseek-ai/dsh-api-session-controller/lib/types/types.d.ts`
中的 `SessionCancelRequest` 只有 `sessionId`；
`SessionCancelValue` 只有 `accepted: true`。公开 `cancel` 文档说明它请求
取消当前活跃回合、保留 inbox，没有 expected run / turn 前置条件，也不证明已终止。

DS Bot 的群成员停止与整群停止分别有自己的范围语义；整群停止涉及群轮次及
所有成员在本群的工作，不能拿来冒充单 Run 控制。

遵照总计划第 11.4 节的降级约束，本轮不新增停止接口，不接入私有宿主状态，不修改 DSH。
BH-014 的原子精确停止仍被宿主公开能力阻挡，不能记为已完成。

## 交互

- 每条活跃运行显示「查看执行会话」，保留运行状态、所属群或私聊及耗时。
- 使用该 Run 的 entity / session / group 身份导航，不能拿当前筛选房间或
  Bot 默认私聊替代。2D 全部群聊同时显示多个运行时尤其如此。
- Bot 群运行打开群聊，提示到群详情中找到对应成员并确认当前工作后停止。
  私聊和普通 Agent 打开所属会话；子 Agent 继续由服务端解析原生子会话地址。
- 按钮只是导航。提示用户在原会话确认当前工作后操作，不显示「已停止」或
  暗示导航会取消任务。原生界面负责真实操作和权限。
- 断线或请求中禁用入口；外部 Agent、缺失会话、身份或群归属不一致不允许
  回退到其他会话。只读宿主允许查看，明确仍为只读。
- 服务端使用现有 `resolve` 重新读取目录；已移除或轮转掉的会话返回不可用。
  导航期间回合可能自然结束或切换，这不构成任何停止操作。
