# BotHub：主题、画质与标签密度

2026-11-08。继办公环境切片，推进 P2 和 P4；本轮不修改 DS Bot 桥接。

## 实现范围

- 跟随宿主深浅模式，使用继承的主题表面色、强调色和状态色；建筑表面与灯光同步变化，木材、植物等保留物理材质。主题变化不重建场景。
- 场景内提供节能、均衡、精细三档画质。默认均衡；分别限制像素比与阴影分辨率，节能关闭阴影。切换不丢失镜头或选择，释放旧阴影贴图。
- 只在本机浏览器保存画质，无团队数据或身份信息；存储不可用时继续使用，非法旧值回退均衡。
- 标签按键盘焦点、选择、房间、待处理／工作状态排序，重叠时隐藏低优先级标签。隐藏标签保留 Tab 顺序，聚焦时立即出现并优先避让；2D 仍提供完整列表。
- 不加入环境动画；继续按需绘制，系统减少动态效果下行为不变。

## 验收

- 单元测试覆盖画质输入和存储异常、标签重叠／边界／焦点优先、主题材质可逆切换与资源复用。
- 真实 DSH + 隔离 mock 验证画质持久化、主题切换、导航保持、键盘标签、2D 降级和资源释放。
- 独立基准使用实际渲染器和明确标记的合成 20／50 席位，记录完整画面绘制调用数、交互帧间隔和同步提交耗时；不将 JS 耗时称作 GPU 耗时。
- 有界循环检查 GPU 对象和监听器释放；不把短期检查称为全天稳定性验收。
- 构建、测试、lint、生成一致性通过后记录结果；本地截图按录制技能处理，mock 优先于技能的真实密钥建议。

完成度与固定权重见 [进度台账](2026-11-08-dsh-bothub-progress.md)。

### 单机规模基准

固定环境：Windows `10.0.26300`，AMD Ryzen AI 9 HX 370，80 GiB RAM，
Radeon 890M／ANGLE D3D11，Chrome `156.0.8078.80`，独立 headless context。
视口 1920×1200，场景 **1920×1080**，设备像素比 1，无其他自动化浏览器并发跑分。

合成数据为一个公共区内 20／50 个不同成员，实际办公家具和角色渲染器；
标签使用简化的成员文本 DOM，经实际标签布局算法定位。无 DSH 网络、
React 页面开销、100 Run 或事件风暴，因此不是完整应用压力验收。
每档预热 10 帧，再交替左右旋转采样 120 帧。CPU 数值包含渲染提交和标签
排布回调，**不代表 GPU 完成时间**；帧间隔由 rAF 采样，非 GPU timestamp。

| 席位 | 画质 | 回调 CPU p95 | 交互帧间隔 p95 | 稳态最大绘制调用 |
|---|---|---:|---:|---:|
| 20 | 节能 | 1.7ms | 17.9ms | 344 |
| 20 | 均衡 | 2.5ms | 17.4ms | 344 |
| 20 | 精细 | 2.4ms | 17.4ms | 344 |
| 50 | 节能 | 3.8ms | 17.5ms | 794 |
| 50 | 均衡 | 4.4ms | 17.5ms | 794 |
| 50 | 精细 | 4.3ms | 17.7ms | 794 |

稳态数值低于原计划 33ms 的单机场景目标。首次创建／首次切换阴影需要
编译 shader：本次单次 CPU 回调约 42–97ms；此开销未计入预热后的 p95。
50 席位重绘阴影的那一帧为 1534 次绘制；静态阴影缓存后稳定为 794。
家具已批处理，角色尚未批处理，后续可据此优化。

每个规模另外循环 30 轮“节能→均衡→精细”。同档资源计数始终一致：
80 个 buffer，节能 7 个 texture，阴影档 9 个 texture，一个 context。
静止 1 秒没有新绘制。卸载显式释放业务资源并释放 context 后归零；
Three 内部每个 context 的 5 个默认纹理由 context loss 回收，而非
逐个 `deleteTexture`。未用这些短期计数代替全天 JS heap 或显存分析。

复现：`node dsh-bothub/scripts/build-scene-benchmark.mjs`，
为生成的 `.playwright-mcp/bothub-scene-benchmark/` 提供本地 HTTP 服务，
在上述 viewport／DPR 下依次 `await runBenchmark({count:20})` 和
`await runBenchmark({count:50})`。测量代码只在 dev 中，生产包不暴露测试钩子。

原始结果和脚本：`.playwright-mcp/bothub-quality/benchmark.json`、
`verify.json`、`benchmark.mjs`、`verify.mjs`。它们为 gitignored 本地产物。
