# BotHub：统计与视图成员范围一致

用户反馈：3D 场景只有 6 位 Bot，顶部却显示 9 位成员。场景已过滤非 Bot，
顶部仍直接读取完整监控快照的 entities/runs，导致统计范围不一致。

## 实现与验收计划

- 3D 顶部统计仅包含 Bot，复用场景的实体类型判断；标签明确为 Bot members。
- 成员按身份计数，不累计跨群席位，不受搜索、群、状态筛选及渲染截断影响。
- 执行数只包含这些成员的运行；待处理人数只包含这些成员的真实待处理状态。
- 2D 保留全量成员统计及 Agent/子 Agent 导航；未加载统计保持占位符。
- 测试覆盖 6 Bot + 3 非 Bot、并发运行、跨群重复席位、无数据及空团队。
- 同步双语说明、构建 client.js，运行 BotHub 测试、生成一致性和 lint。
- 本轮只改客户端，不修改监控协议或用户数据；真实 Desktop 验收单独记录。

## 验证结果

- BotHub `npm test`：110/110 通过，0 失败。
- `npm run build`、`npm run check`、`npm run lint` 通过。
- 新增打包客户端组件测试，使用模拟 React hooks 调用真实 Hub，触发 2D/3D
  按钮，确认成员/运行/待处理数及标签随视图切换；不是浏览器或 Desktop 验收。
- 本轮没有安装、发布或重启用户 Desktop；保留工作树中其他既有修改。
